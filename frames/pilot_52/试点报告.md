# 单框试点报告：分图框 #52（纯视觉管线 Phase 2）

## 选框理由
- 框#52（id=52，lbl=744，bbox 图纸单位 [109613.9, -6434.9, 110451.5, -5860.1]）
- 中等密度代表框：Phase 1 抽样显示约 6 个真器件框，有标题栏（底部）、表头（顶部），能验证过滤逻辑
- 避开：#34（内容稀疏）、#1（嵌套大矩形问题未决）

## 流程（只看渲染像素）
1. 渲染：框 bbox 裁切，8px/单位（≈300DPI量级），6700×4598px，关闭 00_BACKGROUND 图层
2. 二值化（Otsu）→ 细化（Zhang-Suen）→ 骨架连通域 → 实心圆点判定 → 导线网络
3. 器件框：多尺度矩形检测 → 过滤（底部标题栏网格、顶部表头小格剔除；要求边框有导线接入）
4. 端子圆环：HoughCircles 检测 → 导线端点50px内有关联 → 400px内最近器件框
5. 文字：141 个文字块检测（OCR 识别引擎不可用，未识别）

## 结果统计
- 导线网络：372 条（另 36 条为器件框边框，已排除）
- 器件框：6/6 全对（Integrated Power Brake BD176、FL/FR/RL/RR Speed Sensor、 Brake Fluid Level Sensor BD121），标题栏 0 误判
- 器件关联导线：27 条（经端子圆环）
- 框边界端口：22 个
- 悬空：323 条（90% <267px，多为文字碎片/箭头残件；23 条 >300px 为真实导线，关联链不完整）
- 端子圆环：111 个检出
- 文字块：141 个检测，0 个识别（tesseract 被 VM 重置删除，apt 受限装不上）

## 人工看图结论（overlay.png）
- 导线追踪：每根导线独立成网，无断裂、无错误合并；67 个实心圆点正确处理
- 器件框：6 个全对，无标题栏格子混入
- 发现的画法 convention：导线在端子圆环处终止（不直接进器件框），圆环旁有引脚标注（如 BD219-2）；圆环到器件框有 22~156px 间隙

## 能否复制到其余 121 框？
**能，核心流程通用**。但有 4 个瓶颈：

1. **渲染速度**（最大瓶颈）：单框 154 秒 × 122 ≈ 5.2 小时。ezdxf matplotlib 后端慢。需并行/降 DPI/换渲染器。
2. **导线-器件关联不完整**：27/372。长导线经端子圆环的链式关联已实现但覆盖不全；跨框导线需 Phase 3 端口匹配。
3. **OCR 不可用**：From-To 无文字标签。需解决引擎问题或接受无标签。
4. **标题栏过滤的泛化性**：本框标题栏格子因尺寸小被自然滤掉，其他框布局不同需验证。器件框检测在 Phase 1 抽样中曾把标题栏格子误判，本框运气好。

## 已知局限（不编造）
- trace.py 的圆点判定只处理实心圆点；本图用空心圆环做接线点（未处理，对导线级 From-To 可接受）
- HoughCircles 会把文本中的 'o'/'0' 误检为圆，靠"50px 内有导线端点"过滤
- 端子圆环到器件的关联是几何最近（400px 内），无 OCR 时无法用引脚标注校验
- 31 个零端点网络（文字/箭头/符号轮廓闭环）已排除在导线外
